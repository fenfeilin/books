# 鼠小弟爱数学1

**标签**： #绘本/科学 #数学启蒙 #适龄/2-6岁

## 简介
官方指导阅读年龄2-4岁/4-6岁，通过小老鼠艾伯，艾达姐弟两和伙伴们的趣味故事呈现一个数学概念，为初次接触数学的孩子创造了一个奇妙而亲切的数学概念。 先按当前阶段把它归为 科学/数学启蒙。

## 适合怎么用
- 把它当成分类、比较、观察和生活联想的材料。
- 先问“像不像/一样不一样/多不多”，再慢慢加深。

## 当前判断
- 更适合做自然启蒙，不适合硬背结论。
- 如果孩子先对图片有兴趣，就先顺着图聊，不要急着讲完。
