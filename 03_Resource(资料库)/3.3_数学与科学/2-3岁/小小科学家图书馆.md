# 小小科学家图书馆

**标签**： #绘本/科学 #食物来源 #植物观察 #适龄/2-4岁 #生活认知

## 简介

家中已有并实际读过的科学启蒙绘本。当前已知反馈只涉及“水稻/小麦”这本，孩子关注到里面都是吃的。其他分册目录、套系总册数和孩子偏好待补。

这套当前不按“科普知识”推进，而作为生活经验书：从“米饭、面包、面条这些能吃的东西”连接到“植物长出来、被收起来、做成食物”。2岁4个月阶段只抓可看、可摸、可吃、可做的具体经验，不讲完整农业流程、加工链或抽象因果。

## 使用轨迹（按月龄）

> 记录：整体观察、颜色/花纹匹配、旋转试错、放入方式、检查习惯、求助表达、语言输出、轮流意识。
## 适合怎么读

1. **先找吃的**：米饭、面包、面条、馒头、饼干，只要孩子能指出熟悉食物即可。
2. **再看植物**：水稻、小麦、田地、麦穗、谷粒，只讲“长出来”，不解释复杂结构。
3. **最后做生活迁移**：拿家里的米、面粉、面包或面条，摸一摸、闻一闻、装进碗里。

一次只保留 1 个问题：

- “你看到什么吃的？”
- “这是米饭还是面包？”
- “水稻/小麦在哪里？”
- “这个最后可以变成什么？”

## 亲子拓展与核心句型

中文：

- “这是米，煮熟变米饭。”
- “这是小麦，可以做面包/面条。”
- “先长出来，再收起来，最后做成吃的。”
- “我们碗里也有米饭。”
- “摸一摸，米粒小小的。”

English：

- `Rice. We eat rice.`
- `Wheat. Bread is made from wheat.`
- `First it grows. Then we eat.`
- `Put rice in the bowl.`
- `Same food.`

## 同系列下一步候选

分册目录待补，先按家中实际有书选择，不盲目新增未拥有资源：

1. **水稻/小麦复读**：继续巩固食物来源；降级为只找米饭/面包。
2. **水果或蔬菜主题分册（如家中有）**：孩子更容易从吃过的食物进入；降级为只做颜色和名称。
3. **动物/农场主题分册（如家中有）**：可接 [[Wplay]] Farmer 或 Doctor；降级为只找动物和声音。
4. **身体/生活习惯主题分册（如家中有）**：适合接洗手、吃饭、睡觉；降级为做动作。
5. **天气/自然主题分册（如家中有）**：可接阳光、雨水帮助植物长；降级为只看 sun/rain。
6. **机器/工具主题分册（如家中有）**：若孩子对车、开关、机器有兴趣，可只看工具动作；降级为找轮子、按钮、车。

## 后续观察点

- 孩子最关注的是食物、植物、田地、机器，还是吃饭场景。
- 能否把书里的米/面迁移到家里真实米饭、面包、面条。
- 能否听懂两步关系：`长出来 -> 做成吃的`。
- 是否出现新词：米饭、面包、面条、水稻、小麦、田、种、长大。
- 是否能把 `same / match` 用到食物图案或真实食物配对。
