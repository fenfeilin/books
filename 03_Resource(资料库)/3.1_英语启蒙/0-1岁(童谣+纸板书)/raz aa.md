# RAZ AA Level（最入门分级读本）
**标签**：#绘本/英语 #分级阅读 #适龄/1-2岁 #RAZ

## 书本简介
RAZ-Kids体系中最基础的等级（AA级），定位幼儿前阅读阶段。每页仅1-3个单词，配合大幅清晰图片。词汇以日常基础名词和简单动词为主，句式极度简单重复（I see a... / Here is a...）。核心价值不在于"读"，而是帮助建立英文与图片的联系，作为最初语音启蒙输入，不卡认知。

## 亲子拓展/核心句型
- 核心句型：I see a ___. / This is a ___. / Here is a ___.
- 拓展玩法：指着图片问"What do you see?"，引导孩子模仿说出名词；生活中见到同类物品时用英文对应
