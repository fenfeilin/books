**标签**： #分级阅读/科普 #适龄/1-4岁 #Jump分级读物 #STEAM教育

##  系列简介
Jump分级读物是一套体系完整的科普分级读物，核心参考美国三大教育纲要（CCSS、NGSS、C3）。蝌蚪系列（Tadpole）共50册，图片均为高清实拍图，视觉冲击力强。
- **适龄建议**：1岁半以上亲子共读，4岁以上尝试自主阅读。
- **难度阶梯**：
  - **A级**：了解动词、名词+元音
  - **B级**：特征性描述词+元音
  - **C级**：尝试描述一样物体+单词拼写
  - **D级**：总结性特征
  - **E级**：跨学科概念思考
- ** 妈妈阅读建议**：1-2岁主抓“名词+动词”（日读5-8本）；2-3岁主抓“高频词+自然拼读+跨学科思考”（日精读2-3本），利用本套书引导爱背诵的宝宝观察首字母发音。

#  单本绘本笔记库 (03_Resources)

## 一、 动物主题：My First Animal Books (动物系列)

### 1. Koalas (考拉)
**标签**：#绘本/英语 #适龄/1-2岁 #难度A
- **🎯 核心学习点**：
  - **1-2岁 (词汇/动词)**：climbs(攀爬), eats(吃), grabs(抓取), koala(考拉), rides(骑乘), sleeps(睡觉), walks(行走)。
  - **2-3岁 (高频词与拼写)**：a, is, it。学习 /k/ 音，由字母 c 拼写（如 climbs）；长 /e/ 音，由 ea 拼写（如 eats）；长 /e/ 音，由 ee 拼写（如 sleeps）。
- **💬 读后拓展**：考拉是为在树上生活而进化的。它们甚至吃树叶！如果读者可以变成一种动物，会选择生活在哪里呢？是树上、水里，还是空中？作为一种动物，它们需要在栖息地中做什么？请读者把自己画成特定栖息地中的动物并分享。
- **📖 绘本翻译**：一只考拉！ / 它走着。 / 它在爬（树）。 / 它（用爪子）抓。 / 它吃（树叶）。 / 它骑（在妈妈的背上）。 / 它睡觉。

### 2. Pandas (熊猫)
**标签**：#绘本/英语 #适龄/1-3岁 #难度B
- **🎯 核心学习点**：
  - **1-2岁 (动词+身体部位)**：climbs, eats, forest, fur, panda, paws, plays, sleeps。
  - **2-3岁 (高频词与拼写)**：a, has, in, is, it。长 /ɑ/ 音，拼写为 ay（如 plays）；长 /e/ 音，拼写为 ea（如 eats）；长 /e/ 音，拼写为 ee（如 sleeps）。
- **💬 读后拓展**：向读者说明熊猫是熊类。还有哪些其他种类的熊？读者能说出它们的名字吗？熊猫与其他熊类（如北极熊、黑熊或灰熊）有何相似之处？又有何不同？
- **📖 绘本翻译**：一只熊猫在森林里。 / 它有毛。 / 它有爪子。 / 它爬（树）。 / 它吃（竹子）。 / 它玩耍着。 / 它睡觉。

### 3. Sloths (树懒)
**标签**：#绘本/英语 #适龄/1-3岁 #难度B
- **🎯 核心学习点**：
  - **1-2岁 (动词+身体部位)**：brown, claws, climbs, eats, fur, hangs, holds, sleeps, sloth, tree。
  - **2-3岁 (高频词与拼写)**：a, has, in, is, it, on。/k/ 音，由 c 拼写（如 claws、climbs）；长 /e/ 音，由 ea 拼写（如 eats）；长 /e/ 音，由 ee 拼写（如 sleeps、tree）。
- **💬 读后拓展**：让读者翻阅整本书。他们看到书中的树懒在做什么？树懒在树上做什么？哪些身体部位帮助树懒在树上生存？请读者在书中分别指出每个例子。
- **📖 绘本翻译**：一只树懒（挂）在树上。 / 它有着棕色的皮毛。 / 它有爪子。 / 它爬（树）。 / 它挂（在树上）。 / 它吃（叶子）。 / 它抓牢（树干）。 / 它睡觉。

### 4. Narwhals (独角鲸)
**标签**：#绘本/英语 #适龄/2-3岁 #难度C
- **🎯 核心学习点**：
  - **1-2岁 (身体部位)**：air, bye, comes, flippers(鳍肢), ice, lives, narwhal, pod(群), spots, swims, tail, tusk(长牙), whale。
  - **2-3岁 (高频词与拼写)**：a, by, gets, has, I, in, it, see, up。长/a/音，拼写为ai；长/e/音，拼写为ee；短/ɪ/音，拼写为i；短/ʌ/音，拼写为u。
- **💬 读后拓展**：解释独角鲸是鲸鱼，不能在水下呼吸，会浮到水面呼吸空气。空气(air)有长/a/音。让读者找书中其他长/a/音单词(拼写为ai，如tail)，并在黑板上列举更多。
- **📖 绘本翻译**：我看到了一根尖牙！ / 鲸鱼会游泳。 / 它的身上有斑点。 / 它有鱼鳍。 / 它有一条尾巴。 / 它潜入水里。 / 它来到水面上。 / 它需要呼吸空气。 / 独角鲸是群居动物。 / 它在浮冰旁游泳。 / 再见，独角鲸！

### 5. Deer Fawns (小鹿)
**标签**：#绘本/英语 #适龄/2-3岁 #难度C
- **🎯 核心学习点**：
  - **1-2岁**：baby(幼崽), deer, drinks, eats, fawn(小鹿), grows, hides, learns, loses, spots(斑点), walks。
  - **2-3岁**：a, has, I, is, it, see, the。长元音/e/拼写为ee, ea, y；长元音/o/拼写为ow(grows)；r控制元音(learns)。
- **💬 读后拓展**：解释斑点起到伪装(camouflage)的作用，能帮助事物与周围环境融为一体。孩子们能说出其他具有特殊标记或颜色以起到伪装作用的动物吗？
- **📖 绘本翻译**：我看到一只小鹿。 / 这是一只鹿宝宝。 / 它有斑点。 / 小鹿在学（走路）。 / 它行走。 / 它藏在（草丛中）。 / 它吃（妈妈的母乳）。 / 它喝着水。 / 它逐渐长大。 / 它身上的斑点消失了。

### 6. Parrots (鹦鹉)
**标签**：#绘本/英语 #适龄/2-3岁 #难度C
- **🎯 核心学习点**：
  - **1-2岁**：beak(喙), birds, claws(爪子), eats, feathers(羽毛), fly, live, parrot, pretty, trees, wings。
  - **2-3岁**：a, has, have, I, in, it, see, they。/k/音拼为c；长/e/音拼为ea, ee, y；长/ɪ/音拼为y(fly)。
- **💬 读后拓展**：讨论字母 y 发出的不同音（长/e/如pretty，长/ɪ/如fly）。在黑板上列出其他例子并请孩子拼写。
- **📖 绘本翻译**：我看见一只鹦鹉！ / 它有一个喙。 / 它在吃（食物）。 / 它有爪子。 / 鹦鹉生活在树上。 / 它们有羽毛。 / 它们有翅膀。

### 7. Hedgehogs (刺猬)
**标签**：#绘本/英语 #适龄/2-3岁 #难度C
- **🎯 核心学习点**：
  - **1-2岁**：claws, digs, eats, fox, good, hedgehog, hunts, keep, night, oh, quills(刺), rolls, safe, sleeps, wakes, woods。
  - **2-3岁**：a, ball, has, in, into, is, it, no, the, up。复合词(hedgehog)；/qu/音(quills)；c发/k/音；ea/ee发长音/e/。
- **💬 读后拓展**：刺猬遇到危险卷成球，用锋利的刺保护自己免受狐狸伤害。读者还能想到其他动物的防御方式吗（爪子、壳、毒刺）？如果能拥有一种会选什么？
- **📖 绘本翻译**：一只刺猬（从冬眠中）醒了。 / 它在森林里。 / 哦，不！ / 狐狸在狩猎。 / 刺猬将自己滚成一个球。 / 刺能保证它的安全。 / 它有爪子。 / 它挖着洞。 / 它吃（虫子）。 / 它睡觉。 / 晚安！

### 8. Owlets (小猫头鹰)
**标签**：#绘本/英语 #适龄/2-3岁 #难度C
- **🎯 核心学习点**：

- **💬 读后拓展**：思考猫头鹰的身体部位（羽毛、爪、鸟喙）帮助它做什么？它为什么需要这些部位生存？与其他鸟类有哪些相似处？
- **📖 绘本翻译**：这个小宝宝是什么？ / 一只小猫头鹰！ / 它生活在森林里。 / 它呆在巢里。 / 它有羽毛。 / 它有爪子。 / 它有一个喙。 / 它吃着东西。

### 9. Llamas (羊驼/美洲驼)

## 二、 日常生活主题：First Routines (日常习惯)

### 14. Exercising (锻炼身体)
**标签**：#绘本/英语 #适龄/1-2岁 #难度A
- **🎯 核心学习点**：
  - **1-2岁 (动词)**：dance(跳舞), exercising(锻炼), jump(跳跃), play(玩耍), rope(绳索), run(跑步), skip(单脚跳/跳绳), walk(走路)。
  - **2-3岁**：I；标点感叹号；长元音/a/(play)；/s/音由c拼写(dance)；短元音/u/(jump, run)。
- **💬 读后拓展**：解释锻炼就是活动身体，并和宝宝一起动起来（TPR教学）。将宝宝最喜欢的活动方式写在黑板上。
- **📖 绘本翻译**：我散步。 / 我跳舞。 / 我奔跑。 / 我单脚跳。 / 我玩耍。 / 我跳起来（双腿跳）。 / 我跳绳！

### 15. Eating Healthy Foods (吃健康食物)
**标签**：#绘本/英语 #适龄/2-3岁 #难度B
- **🎯 核心学习点**：
  - **1-2岁**：apples, carrots, cheese, eat(ing), eggs, foods, healthy, oatmeal, what。
  - **2-3岁**：do, I, let's, you；复合词(oatmeal)；长元音/e/拼写为ea；/oo/拼写为oo；/ee/拼写为ee。
- **💬 读后拓展**：讨论五大食物组。向读者展示更多健康食物的例子，分辨它们属于哪一组以及宝宝最爱吃哪一组。
- **📖 绘本翻译**：让我们吃健康的食物！ / 我吃苹果。 / 我吃鸡蛋。 / 我吃奶酪。 / 我吃胡萝卜。 / 我吃燕麦粥。 / 你会吃哪些食物呢？

### 16. Bedtime (睡觉时间)
**标签**：#绘本/英语 #适龄/2-3岁 #难度C
- **🎯 核心学习点**：
  - **1-2岁**：bedtime, body, book, brush, clean, comb, good, hair, night, pajamas(睡衣), put, read, teeth, up, wash。
  - **2-3岁**：a, I, my, on, we。复合词(bedtime)；长音/e/(clean, read, teeth)；长音/e/拼写为y(body)；多音节词(pajamas)；/oo/(book, good)。
- **💬 读后拓展**：谈论睡前常规。询问学生的睡前常规是什么，哪些事情是相似的？还能想到其他类型的常规吗？
- **📖 绘本翻译**：我收拾好(玩具)。 / 我洗澡。 / 我洗头发。 / 我穿上睡衣。 / 我梳好头发。 / 我刷牙。 / 我们读一本书。 / 晚安！

### 17. Morning Routine (早晨)
**标签**：#绘本/英语 #适龄/2-3岁 #难度C
- **🎯 核心学习点**：
  - **1-2岁**：bathroom, bed, breakfast, brushes, eat, goes, good, hair, hands, makes, morning, ready, school, teeth, washes。
  - **2-3岁**：are, for, he, her, his, she, the, to, we。复合词(bathroom, breakfast)；长音/a/(hair)；长音/e/(teeth, eat)；/oo/(bathroom)。
- **💬 读后拓展**：解释日常惯例是固定行为顺序。例如穿衣服和吃早餐。他们还能想到哪些早晨惯例？
- **📖 绘本翻译**：早上好！ / 他去卫生间。 / 他在洗手。 / 她梳着她的头发。 / 他刷着牙。 / 他在整理床。 / 我们吃早餐。 / 我们准备好去上学了！

## 三、 🌲 主题：Outdoor Explorer (户外探索)

### 18. I See Trees (我看到了树)
**标签**：#绘本/英语 #适龄/1-3岁 #难度A
- **🎯 核心学习点**：
  - **1-2岁**：bark(树皮), branch(树枝), flower, fruit, hole, home, pinecone, nest, nut, root, seed, tree, trunk(树干), twig(嫩枝)。
  - **2-3岁**：have。重点学习复数词缀：leaves, trees, trunks, twigs 及发音；不规则复数；词首辅音簇。
- **💬 读后拓展**：让学生思考动物如何利用树木（栖息、获取食物等），鼓励分享并将想法写下来。
- **📖 绘本翻译**：树有树干。 / 树有树皮。 / 树有树枝。 / 树有细枝。 / （一些）树长着针叶。 / 树有绿叶。 / 树绽放出花朵。 / 树结出果实。 / 树结出坚果。 / 树结出种子。 / 树有（弯弯曲曲的）根。 / 树（上）有鸟巢。 / 树（干）有许多小洞。 / 树有（动物们的）家。

### 19. I See Birds (我看见鸟儿)
**标签**：#绘本/英语 #适龄/1-3岁 #难度A
- **🎯 核心学习点**：

- **💬 读后拓展**：思考鸟类的其他行为。邀请孩子表演行为让其他人猜；拼读单词时预测首字母。
- **📖 绘本翻译**：老鹰在天空翱翔 / 鸭子在嘎嘎叫。 / 小麻雀在（草地上）跳着。 / 乌鸦在（枝头）啼叫。 / 母鸡在啄（食物）。 / 知更鸟在（枝头）唱着歌。 / 天鹅在（水面）游泳。

### 21. I See Rocks (我看到了石头)

- **📖 绘本翻译**：看这些石头！ / 这块石头（的表面）凹凸不平。 / 这块石头（的表面）很光滑。 / 这块石头是彩色的。 / 这块石头的颜色很单一。 / 这是一块化石。 / 这块石头里藏着一个惊喜！

### 23. I See Leaves (我看见树叶)
