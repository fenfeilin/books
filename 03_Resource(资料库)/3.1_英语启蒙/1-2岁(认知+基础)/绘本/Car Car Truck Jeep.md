# Nick Sharratt 童谣改编三本

这套是 Katrina Charman 写文、Nick Sharratt 画图的童谣改编绘本。三本分别借用孩子熟悉的经典旋律，把低幼最爱的交通工具、动物、海盗冒险做成节奏很强的唱读书：

- `Car, Car, Truck, Jeep`：套用《Baa, Baa, Black Sheep》的旋律，主线是各种交通工具一路出发、加油、过红绿灯、上山、施工、救援，最后进入睡前。
- `Go, Go, Pirate Boat`：套用《Row, Row, Row Your Boat》的旋律，主线是海盗船出海、遇浪、看地图、找宝藏、躲鲨鱼，最后回家喝茶。
- `The Whales on the Bus`：套用《The Wheels on the Bus》的旋律，主线是各种动物坐上各种交通工具，鲸鱼上公交、鹤坐火车、蜜蜂滑雪、绵羊开吉普，荒诞感很强。

## 1. 这套书总体讲什么

### 核心主题

这套的本质不是“单纯认交通工具”或“单纯唱童谣”，而是把经典童谣变成了三类低幼可理解的身体经验：

| 分册 | 表层主题 | 深层能力 |
| --- | --- | --- |
| Car, Car, Truck, Jeep | 交通工具、车辆声音、路上场景 | 听懂交通名词、动作词、出行顺序和红绿灯规则 |
| Go, Go, Pirate Boat | 海盗船、海洋动物、寻宝冒险 | 听懂动作指令、空间移动、冒险情节和假装游戏 |
| The Whales on the Bus | 动物 + 交通工具的荒诞组合 | 动物名、交通工具名、声音模仿、押韵和幽默感 |

三本共同特点：

- 旋律入口强：孩子不一定听懂每个词，但会被节奏带住。
- 图像识别强：Nick Sharratt 的画面颜色块大、轮廓清楚，适合低幼指认。
- 词汇跨度大：既有 car, bus, train 这种基础词，也有 hovercraft, helicopter, submarine, glider, anchor, hoist, baboon, llama 这类低幼并不常见的词。
- 情节不是线性故事书那种“起承转合”，而是童谣式推进：一页一个场景，一页一个动作/声音/交通工具。

### 难度判断

这套在低幼童谣书里不算简单，尤其是 `Car, Car, Truck, Jeep` 和 `Go, Go, Pirate Boat`。难点主要不在句子长度，而在三个地方：

| 难点 | 具体表现 | 带读处理 |
| --- | --- | --- |
| 陌生名词多 | hovercraft, jumbo jet, dumper truck, submarine, glider, anchor, plank | 不要求一次记住，先用“看图知道是什么”替代背单词 |
| 节奏快 | 童谣换词密集，孩子容易跟不上 | 第一遍只听旋律，第二遍再找图 |
| 画面信息多 | 同一页常有多辆车、多只动物、多条动作线 | 每页只抓一个目标：找车、做动作、模仿声音三选一 |

### 适合年龄

- **1.5-2 岁**：适合当熏听和指图书，不建议精读。孩子只要能指车、指动物、跟着做声音，就算读到了。
- **2-2.5 岁**：最容易出现“突然爱上”的阶段，尤其是车迷。可以用玩具车、动物模型、假装开船来演。
- **2.5-3.5 岁**：可以进入句型和押韵意识，开始让孩子补最后一个词、替换动物/车辆。
- **3.5 岁以上**：适合做改编童谣游戏，比如自己编 “The cats on the train...”。

### 适合怎么读

这套不要按“分级阅读”来读，也不要逐词翻译。更适合按“童谣书三步法”：

1. **先听旋律**：第一遍不打断，成人唱/念出节奏，让孩子感受重复。
2. **再抓主线**：每本只抓一条线，比如车、船、动物，不同时讲完所有细节。
3. **最后玩出来**：把书变成玩具车游戏、沙发海盗船、动物坐车配对游戏。

如果孩子只能听歌、不愿意看书，也正常。这套的第一入口就是声音和节奏，不是认字和复述。

### 推荐阅读顺序

1. **Car, Car, Truck, Jeep**：如果孩子喜欢车，先从这本进。熟悉交通工具，接受度最高。
2. **The Whales on the Bus**：熟悉《Wheels on the Bus》的孩子会很容易进入，动物和交通工具混搭很好笑。
3. **Go, Go, Pirate Boat**：动作最强，但海盗词汇相对陌生。适合孩子已经能玩假装游戏后再精读。

## 2. 详细带读指导

### 共读总原则

#### 第一遍：唱读，不解释

目标是让孩子进入旋律。成人可以夸张一点，用车声、动物声、海浪声带节奏。第一遍只读 3-5 页也可以，不追求完整读完。

家长口令：

- `Listen! It sounds like a song.`
- `Let's sing and point.`
- `You point. I sing.`
- `Which page do you want?`

#### 第二遍：找图，不考词

每页只问一个很简单的问题：

- `Where is the car?`
- `Can you find the whale?`
- `What is in the sky?`
- `Who is on the boat?`

孩子可以用手指回答，不需要开口。低幼英语启蒙里，“听懂并指对”已经是非常重要的输入结果。

#### 第三遍：做动作

把书中的动作变成 TPR：

- 交通书：drive, stop, go, climb, dig, flash, sleep
- 海盗书：row, splash, hold, scrub, dig, climb, walk, run
- 动物交通书：zoom, dive, loop, quack, roar, float, snore

家长不要急着让孩子说完整句。先让身体理解英文，开口会慢慢跟上。

### 分册 1：Car, Car, Truck, Jeep

#### 内容简介

这本从加油站出发，像一首交通工具版的童谣旅行。孩子会看到红色公交车、火车、飞机、拖拉机、摩托车、直升机、出租车、货车、挖掘机、翻斗车、警车、救护车等。整本很适合车迷，但词汇量比普通低幼车车书大很多。

#### 核心词汇

| 类别 | 词汇 |
| --- | --- |
| 基础交通工具 | car, bus, train, truck, jeep, taxi |
| 进阶交通工具 | jumbo jet, tractor, motorbike, hovercraft, helicopter, lorry |
| 工程/救援车 | digger, dumper truck, police car, fire engine, ambulance |
| 路上动作 | drive, pass, stop, go, race, climb, dig, flash, rush |
| 声音词 | beep, honk, chugga, clack, rumble, screech, roar |

#### 核心句型与表达

不要追求逐字复述，可以抓这些可迁移表达：

- `The car goes...`
- `Stop at the red light.`
- `Green light. Go!`
- `Look! A ___ is coming.`
- `It is going up/down.`
- `Time for bed.`

#### 带读流程

**读前 1 分钟：拿玩具车预热**

把 3-5 辆玩具车排出来：

- `This is a car.`
- `This is a truck.`
- `This is a bus.`
- `Ready? Drive!`

孩子如果喜欢，可以先玩红绿灯：

- 红色积木 = `Stop.`
- 绿色积木 = `Go.`
- 黄色积木 = `Slow down.`

**读中：每页只抓一个点**

| 场景 | 带读重点 | 互动方式 |
| --- | --- | --- |
| 加油站 | fuel, tank, fill up | 用积木假装加油 |
| 公交/火车/飞机 | bus, train, plane | 问 `Who is on the bus?` |
| 拖拉机/重载 | heavy, load | 做“推很重”的动作 |
| 摩托车/红绿灯 | stop, go | 玩红灯停绿灯行 |
| 火车 | chugga, clack | 手臂转圈模仿火车 |
| 港口/气垫船 | harbour, hovercraft | 用手掌在桌面“滑行” |
| 直升机 | helicopter, sky | 手指在头顶转螺旋桨 |
| 出租车/货车爬坡 | climb, hill | 玩具车爬枕头坡 |
| 挖掘机/翻斗车 | dig, dump | 米桶/积木假装挖土 |
| 救援车 | siren, flash, rush | 模仿警笛，快速开过去 |
| 睡前页 | yawn, sleep | 让车车排队回车库睡觉 |

**读后 5 分钟：车车路线图**

在地上用胶带贴一条路，设置：

- garage
- gas station
- red light
- hill
- construction site
- bed/parking lot

带孩子一边开车一边说：

- `Fill up the car.`
- `Stop.`
- `Go.`
- `Go up the hill.`
- `Dig, dig, dig.`
- `Park the car. Good night.`

#### 家庭拓展

- 出门看到车时只说一句：`I see a bus/train/taxi.`
- 过马路时迁移：`Red light. Stop. Green light. Go.`
- 睡前把玩具车收进盒子：`Time for bed. Good night, car.`

### 分册 2：Go, Go, Pirate Boat

#### 内容简介

这本是海盗船冒险：小海盗们扬帆出海，遇到海浪、鲸鱼、鲨鱼、章鱼，看地图找宝藏，挖沙、搬宝、走跳板，最后赶在天黑前回家。它比普通低幼船书更像“动作剧本”，非常适合假装游戏。

#### 核心词汇

| 类别 | 词汇 |
| --- | --- |
| 船和海盗 | pirate, boat, anchor, sail, deck, plank, treasure, map |
| 海洋动物 | whale, shark, octopus, dolphin, crab, starfish, seahorse |
| 动作 | raise, hoist, splash, rock, grab, hold, scrub, row, dig, climb, walk |
| 冒险情绪 | bumpy, dark, watch out, home |

#### 核心句型与表达

- `Let's go!`
- `Raise the anchor.`
- `Hoist the sail.`
- `Hold on tight.`
- `Look at the map.`
- `Dig in the sand.`
- `Watch out!`
- `Time to go home.`

#### 带读流程

**读前 1 分钟：搭一艘船**

用沙发垫、纸箱或床单当船：

- `This is our boat.`
- `You are the pirate.`
- `Here is the map.`
- `Let's find treasure.`

**读中：把每一页读成动作口令**

| 场景 | 带读重点 | 互动方式 |
| --- | --- | --- |
| 出海 | boat, sea | 身体左右晃，假装船在海上 |
| 起锚/扬帆 | anchor, sail | 用绳子/丝巾做动作 |
| 海浪 | splash, rock | 左右摇，夸张说 `Splash!` |
| 鲸鱼 | whale, bumpy | 坐在垫子上“颠簸” |
| 擦甲板 | scrub | 拿小毛巾擦地/擦桌 |
| 看地图 | map, find | 画一张简单藏宝图 |
| 挖沙 | dig | 在米桶/沙坑里找积木宝藏 |
| 找到宝藏 | treasure, chest | 打开盒子说 `Treasure!` |
| 鲨鱼/章鱼 | watch out | 快速躲进船里 |
| 走跳板 | walk, plank | 在地上放一条毛巾当 plank |
| 回家 | home, tea | 假装倒茶，结束游戏 |

**读后 5 分钟：家庭寻宝**

准备一个小盒子当 treasure chest，里面放贴纸、积木或小车。画一张极简地图：

1. sofa
2. table
3. pillow island
4. treasure box

家长说：

- `Look at the map.`
- `Row to the island.`
- `Dig, dig, dig.`
- `Open the chest.`
- `You found it!`

#### 家庭拓展

- 洗澡时可以说：`Splash, splash.`
- 收拾桌面时说：`Scrub the table.`
- 去沙坑时说：`Dig in the sand.`
- 玩海洋动物时说：`Watch out for the shark.`

### 分册 3：The Whales on the Bus

#### 内容简介

这本是三本里最荒诞、最适合逗笑的一本。它把动物和交通工具强行配对：鲸鱼坐公交，鹤坐火车，蜜蜂滑雪，绵羊开吉普，海豹坐潜艇，老虎开滑翔机，鸭子坐卡车，龙坐马车，山羊坐船，蛇滑冰，狒狒坐热气球，美洲驼穿睡衣睡觉。孩子会在“这不可能吧”的幽默里记住动物、交通工具和声音。

#### 核心词汇

| 类别 | 词汇 |
| --- | --- |
| 动物 | whale, crane, bee, sheep, seal, tiger, duck, dragon, goat, snake, baboon, llama |
| 交通/载具 | bus, train, skis, jeep, sub, glider, truck, wagon, boat, skates, balloon |
| 声音/动作 | choo, zoom, dive, loop, quack, beep, roar, sing, slip, float, snore |
| 句型概念 | on/in, go, all day long |

#### 核心句型与表达

这本最适合练“动物 + 交通工具”的组合表达：

- `Who is on the bus?`
- `The ___ is on the ___.`
- `What does it say?`
- `It goes ___.`
- `Is it silly?`
- `Your turn. Put the animal on the vehicle.`

#### 带读流程

**读前 1 分钟：先唱原版旋律**

如果孩子熟悉公交车童谣，可以先唱 10 秒原版，再打开书：

- `This bus is different.`
- `Who is on the bus?`
- `Whales! So silly!`

**读中：每页做“配对 + 声音”**

| 场景 | 带读重点 | 互动方式 |
| --- | --- | --- |
| 鲸鱼公交 | whale, bus | 双手做喷水，问 `Too big?` |
| 鹤火车 | crane, train | 手臂做长脖子，模仿火车声 |
| 蜜蜂滑雪 | bee, skis | 手指从高处滑下来 |
| 绵羊吉普 | sheep, jeep, mud | 玩具车开进“泥地” |
| 海豹潜艇 | seal, sub, dive | 手往下潜 |
| 老虎滑翔机 | tiger, glider, loop | 手在空中绕圈 |
| 鸭子卡车 | duck, truck | 模仿鸭叫和喇叭 |
| 龙马车 | dragon, wagon | 张嘴喷火，夸张 roar |
| 山羊小船 | goat, boat | 假装唱海盗歌 |
| 蛇溜冰 | snake, skates | 手指蛇形滑动 |
| 狒狒气球 | baboon, balloon | 手慢慢往上飘 |
| 睡衣羊驼 | llama, pajamas | 睡前页，收束情绪 |

**读后 5 分钟：荒诞配对游戏**

拿动物玩偶和玩具车，故意配错：

- rabbit on the train
- dinosaur in the bus
- duck on the plane
- bear in the boat

家长问：

- `Is it funny?`
- `Where is the duck?`
- `The duck is on the plane.`
- `What sound does it make?`

#### 家庭拓展

- 洗澡玩潜水：`Dive down. Come up.`
- 坐公交/地铁时：`Who is on the bus/train?`
- 睡前拿睡衣：`Pajamas on. Time for bed.`
- 玩动物配对：让孩子决定哪个动物坐哪辆车，鼓励他发明荒诞组合。

### 三本混读路线

| 阶段 | 目标 | 读法 |
| --- | --- | --- |
| 第 1 周 | 建立旋律和好感 | 每天只唱一本 3-5 页，孩子喜欢哪页读哪页 |
| 第 2 周 | 抓核心词 | Car 抓车，Pirate 抓动作，Whales 抓动物 |
| 第 3 周 | 做家庭游戏 | 玩红绿灯、寻宝、动物坐车 |
| 第 4 周 | 引导输出 | 成人说前半句，孩子补一个词或声音 |

### 家长常见问题

**孩子只爱听歌，不愿意看图怎么办？**

这是正常入口。先把歌当背景输入，等旋律熟了，再拿书让孩子找一两个最显眼的图。不要在孩子兴奋听歌时频繁暂停解释。

**很多词太难，要不要查完再讲？**

不需要。低幼阶段先让孩子通过图像建立模糊理解：这是会飞的、会跑的、会挖土的、会在水里走的。精确词义可以等孩子反复读后慢慢补。

**孩子会不会只记声音，不懂意思？**

如果只放音频，确实容易停留在声音层面。所以第二步一定要用玩具和身体动作承接：车要开、船要摇、动物要坐上车。意思是在游戏里长出来的。

**这套适合当主线吗？**

不适合当唯一主线。它更像“童谣强化 + 兴趣入口 + 口语游戏包”。主线仍然可以搭配 RAZ AA/A、古力小超人、生活场景书。

## 3. 详细内容 + 小红书发文指导

### 内容定位

这篇适合写成“低幼英文童谣书真实带读笔记”，不要写成单纯种草。核心观点可以是：

> 低幼英语启蒙里，童谣书不是用来背单词的，而是用旋律、动作和熟悉主题，把英文先变成孩子愿意重复的声音经验。

这套最值得写的点：

- 旋律熟，孩子容易被带进去。
- 画面大胆，交通工具和动物非常醒目。
- 词汇并不简单，所以读法不能是逐词翻译。
- 车迷、动物迷、喜欢假装游戏的孩子，会比普通孩子更容易爱上。
- 适合从“听童谣”过渡到“看图理解 + TPR 动作 + 玩具复现”。

### 目标读者

- 家里有 1.5-3 岁孩子，正在做英语启蒙的妈妈。
- 孩子喜欢车、动物、海盗、交通工具，但不太愿意坐着读分级。
- 买了英文童谣书，不知道除了放音频还能怎么读的人。
- 读过彩虹兔、巴塔木、古力小超人，想找更有节奏感绘本的人。

### 标题备选

- 2岁车迷突然爱上的英文童谣书，原来要这样读

- **第 4 页适龄判断**：1.5-2 岁听歌指图，2-3 岁玩具复现，3 岁后做替换创编。

- **第 7 页避坑**：不要逐词翻译，不要要求整本跟读，不要把冷门词全背下来。
- **第 8 页我家真实观察**：最难的一本反而可能因为旋律和车车元素逆袭。

## 2岁3个月二次进入用法

2岁3个月反馈显示，孩子对旋律的接受明显早于故事理解。读这套时要把“会唱/愿意听”和“懂故事顺序”分开记录：会跟旋律不代表理解加油、红绿灯、施工、救援或回家睡觉这些流程。

当天用法：

- `Car, Car, Truck, Jeep`：每次只抓 1 条交通流程，如 `stop / go` 或 `dig / dump`，不要整本解释所有车。
- `The Whales on the Bus`：如果孩子熟悉公交旋律，可用动物坐车做荒诞配对，重点问 `Who is on the bus?`
- `Go, Go, Pirate Boat`：海盗词更陌生，先做 `row / dig / open treasure` 三个动作，不急着讲完整寻宝故事。

可直接说：

- `Let's sing first.`
- `Where is the car?`
- `Red light. Stop.`
- `Green light. Go.`
- `Dig, dig, dig.`
- `Time for bed, little car.`
- `Who is on the bus?`

同系列下一步候选：

- 先用 `Car, Car, Truck, Jeep` 做红绿灯和车车回家，最贴近已有交通兴趣。
- 再用 `The Whales on the Bus` 做动物 + 交通工具配对，旋律更熟但逻辑更荒诞。
- 最后用 `Go, Go, Pirate Boat` 做寻宝动作剧本；如果孩子只听歌不看图，就退回唱读暖场。

> 结语：这套书不要急着读成“单词清单”。对低幼孩子来说，先让旋律抓住耳朵，再让图像和动作托住理解，最后才会慢慢长出词汇和句子。
