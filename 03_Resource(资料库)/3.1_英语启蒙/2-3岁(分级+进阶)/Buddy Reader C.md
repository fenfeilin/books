# Buddy Reader C（自然拼读分级读本·C级）
**标签**：#绘本/英语 #分级阅读 #适龄/2-3岁 #自然拼读

## 书本简介
国内引进的自然拼读分级读本Buddy Reader C级，难度介于B级和D级之间。词汇量和句式复杂度较B级明显提升，故事情节有一定逻辑，对认知理解能力要求较高。实测在2岁2个月阶段依然卡认知，建议把A/B级吃透、孩子能自主理解图意之后再引入C级。

## 亲子拓展/核心句型
- 结合已掌握的A/B级句型，尝试引导预测故事走向
- 拓展：看封面猜内容，建立阅读期待感，降低因卡认知产生的排斥感

### 2岁3个月回归用法

近期孩子重新接触 `clownfish and crab` 以及另一本文本涉及 `happy / sad` 的情绪分册。孩子对 `crab` 相关内容有记忆，也能跟着重复句式替换关键词；但如果结尾出现转折、答案不再沿用前面模式，容易继续套原句而说错。

这说明 Buddy Reader C 现在可以少量回归，但目标不是升级刷 C 级，而是用 1 本熟悉书观察“重复句式开口”和“故事转折理解”是否分开发展。

2岁3个月后续反馈：又看 2 本 C 级后，孩子对表情和情绪词的理解更明显，能接住 `happy / crabby / sad` 这类标签。下一步不要急着解释完整情绪原因，先把“看脸/看动作判断情绪”迁移到玩具、家人表情和食物情境里。

带读要点：

- 每次只读 1 本 C 级，前面可以让孩子套句，最后一页要停下来预测。
- 情绪词先用二选一：`Is crab happy or sad?` / `Happy or crabby?`
- 遇到转折页，成人先中文垫一句：“前面都一样，但这一页不一样了。”
- 不要求孩子完整解释情绪原因，先看他能否指出脸、动作或说 `happy / sad / crabby / hungry`。
- 如果孩子能说出情绪词，就加一句原因框架：`He is sad. No ice cream.` / `Crab is hungry.`

可直接说：

- `He is happy.`
- `He is sad.`
- `Crab is crabby.`
- `Look at his face.`
- `This page is different.`
- `What happens now?`
- `Not the same answer.`

同系列下一步候选：

- 先复读孩子记得的 `clownfish and crab`，观察情绪词和结尾转折；降级时只问 `happy or crabby?`。
- 再选 1 本同样重复句式但结尾变化少的 C 级，保护开口信心；降级时让孩子只补关键词。
- 再选 1 本表情明显的 C 级，只看脸和动作，不要求讲原因；降级时成人直接说原因。
- 暂缓连续读多本 C 级；如果孩子只是在套句而不看图，退回 [[buddy reader b]] 或 [[RAZ B]] 做理解观察。
