## 1. 这套书总体讲什么

RAZ C 是从“看图理解关系”继续往“简单叙事和初步科普”走的一层。它既有生活主题，也有明显的思维要求：轮流、情绪、职业、工具、夜晚、青蛙成长、鲨鱼、岩石、太空、食物制作。

如果说 B 级是在练 `what/where/how many`，C 级就开始练 `why/how/what happens next`。孩子需要理解人物意图、事情顺序、简单因果和科普概念。

### 分级定位

| 维度 | 判断 |
| --- | --- |

| 适合阶段 | B 级稳定后；2.5-4 岁亲子共读；也适合做口语问答材料 |

| 读法关键词 | 预测、排序、原因、角色、复述 |

### 适合怎么读

- C 级可以开始“精读一页”：不是每页都问，而是挑关键页做预测和因果。
- 科普书先用中文补背景，再读英文；不必让英语承载全部认知压力。
- 社交情绪类适合和生活场景绑定，如轮流玩玩具、表达 `I want...`、说 `I won't...`。
- 如果孩子听懂故事但不愿意英文回答，可以允许中文回答，再由成人翻成简单英文。

## 2. 带读指导与罗宾记忆曲线打卡

### 单本 7 步带读

1. 封面预测：`Who is in the story?` / `What will happen?`
2. 背景补充：遇到 sharks, rocks, space, nighttime 这类主题，先用中文讲 20 秒。
3. 关键词预教：每本只挑 3-5 个关键词，不做单词表。
4. 正文共读：读完关键页停下，问一个理解题。
5. 因果追问：`Why?` 不要求英文长答，孩子能指图或中文说明也算。
6. 复述支架：用 `First... Then... At last...` 帮孩子串起来。
7. 生活迁移：把核心句迁移成孩子自己的生活句。

### 家长常用英文句

- `What do you think will happen?`
- `Who is this?`
- `What does he/she want?`
- `How does he/she feel?`
- `Why is he/she sad/shy/happy?`
- `What happens next?`
- `First..., then..., at last...`
- `I want ___. / I don't want ___.`
- `Let's take turns.`

### 按主题带读玩法

| 主题 | 带读动作 | 输出目标 |
| --- | --- | --- |
| 情绪社交 | 做表情卡：happy/sad/shy/mad；玩轮流游戏 | 能理解情绪词和 turn-taking |
| 职业工具 | 家里找 tool：spoon, brush, scissors, toy hammer | 能把 job-tool 关系配起来 |
| 食物流程 | 假装做 salsa/potatoes，按 first-next-last 排序 | 能复述 2-3 个步骤 |
| 自然科普 | 用图片讲 frog life cycle、shark kinds、nighttime | 能说出一个原因或变化 |
| 故事类 | 画三格漫画：beginning-middle-end | 能用中文或英文复述主线 |

### 判断是否可以升到 RAZ D

- 能回答 `why/how/what happens next` 中的一类问题。
- 能用中文或英文讲出一本书的主线。
- 能接受科普主题前的背景补充，不明显抗拒。
- 能把书中一句表达迁移到生活，如 `I want...`, `Let's take turns.`

## 3. 小红书发文指导

### 账号定位角度

RAZ C 可以写成“真正开始练理解力的一层”。它适合展示亲子带读老师的专业度：怎么处理孩子不会答 `why`，怎么给科普书补背景，怎么把情绪社交主题读到生活里。

### 适合的发文选题

1. `RAZ C怎么读？开始从what过渡到why`
2. `RAZ C最值得精读的4类主题：情绪、流程、科普、故事`
3. `孩子读RAZ C卡住，不是英语问题，是背景知识不够`
4. `RAZ C带读话术：一页只问一个好问题`
5. `RAZ C复习表：角色、原因、顺序分三次读`

### 笔记结构模板

- 开头：C 级开始不适合纯刷，要加入预测和复述。
- 分析：这一层的难点是因果、顺序、角色和科普背景。
- 展示：用 Feelings、How Frogs Grow、Making Salsa! 各举一个带读问题。
- 给工具：first-then-at last 复述框架 + D0-D30 打卡。
- 结尾：告诉家长允许孩子中文回答，成人再转英文。

### 封面建议

- 大字：`RAZ C：开始问 Why`
- 小字：`2.5-4岁｜情绪｜科普｜复述`
- 画面：一张“what -> why -> retell”的箭头图，加 3 本代表书。

### 可直接使用的正文开头

> RAZ C 我会明显从“读给孩子听”切到“带孩子想一想”。这一层的书开始有情绪、有流程、有简单科普，孩子不会马上英文回答很正常。我的原则是：先保证理解，再慢慢把答案翻成一句简单英文。
