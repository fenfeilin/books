# 牛津树家庭版3

**标签**： #绘本/英语 #分级阅读 #牛津树 #牛津树家庭版 #自然拼读 #适龄/3岁+

## 1. 总体理解：这一级讲什么
家庭版 Level 3 的 Phonics 故事开始更有“阅读训练”的感觉，例如 Such a Fuss、Shops、The Sing Song、The Backpack；First Stories 则有 Poor Old Rabbit、I Can Trick a Tiger、Super Dad、Floppy and the Bone。

**主题定位**：这一阶把声音、词汇和故事理解拧得更紧。主题从家庭和物品扩展到商店、背包、唱歌、动物、爸爸形象、宠物找骨头等，孩子需要开始理解“为什么会这样”和“谁在想办法”。

**难度判断**：Level 3 适合已经能听懂 Level 2 短故事的孩子。这里的句子和情节都更完整，带读重点要从“找东西”慢慢转向“讲发生了什么”。

**适合怎么读**：每本 10-12 分钟。读前看封面预测，读中抓问题，读后用 3 张图复述。Phonics 仍然轻讲，不要把每个词拆得太碎。

**核心能力**：短故事复述、情绪理解、问题-解决结构、押韵和常见拼读模式感知。

**核心词汇/句型**：fuss, shop, sing, backpack, rabbit, tiger, trick, dad, bone, poor, old, super。句型可以抓 `I can...` / `Can you...?` / `What is in...?` / `He/She has...`

## 2. 详细带读指导
### 读前
- 先问封面问题：What can you see? Who is in trouble?
- 如果是 Phonics 书，只预热 2-3 个关键词。
- 如果是 First Stories，先让孩子猜“谁会想办法”。

### 读中
- Such a Fuss 适合讲情绪和声音：Why such a fuss?
- Shops 可以连接真实逛店经验，讲 shop, buy, bag, money。
- The Backpack 适合拿一个包做实物互动：What's in the backpack?
- I Can Trick a Tiger 适合抓 `I can...` 句型，做假装游戏。
- Floppy and the Bone 可以做宠物找东西的故事复演。

### 读后
- 用 First / Then / Finally 做三步复述。
- 让孩子选最喜欢的一页，说中文也可以。
- 把一个句型迁移到生活里：I can jump. I can hide. I can trick Dad.

### 代表书带读
1. **Shops**：真实生活迁移强，适合买东西、装袋、付钱主题。
2. **The Backpack**：可操作性强，适合做“包里有什么”的猜物游戏。
3. **Poor Old Rabbit**：情绪和照顾主题，适合问 rabbit feels...? why?
4. **I Can Trick a Tiger**：句型输出好，孩子容易模仿 `I can...`
5. **Super Dad**：家庭情感强，适合聊爸爸能做什么、孩子能帮什么。

## 3. 详细内容 + 小红书发文指导
### 发文定位
写给读到家庭版3、发现孩子开始能听懂情节的家长。重点强调：这一阶要开始练复述，不只是听音频和跟读。

### 标题备选
- 牛津树家庭版3：从听懂词，走到会讲发生了什么
- Level 3带读笔记：自然拼读和故事理解一起做
- 家庭版3怎么读：用三步复述帮孩子读懂故事

### 正文草稿
Level 3 是一个小转折。孩子不只是认人物、找物品，而是要开始理解故事里的问题和解决办法。

1. 读前先看封面预测，孩子会更想知道答案。
2. 读中别不停翻译，抓住“谁遇到问题、怎么解决”就够了。
3. 读后用 First / Then / Finally 做三步复述，说中文也可以。
4. Phonics 继续轻轻带，不要让自然拼读破坏故事兴趣。

封面文案可以写：`牛津树家庭版3 / 开始练三步复述`

图片脚本：拍 The Backpack 做猜物，拍 I Can Trick a Tiger 做角色扮演，最后放一张复述模板：First / Then / Finally。
