# sight word tales box set

**标签**： #绘本/英语 #分级阅读 #适龄/2-8岁

## 简介
这书共25本，每个故事都以小朋友和动物为主人公，包含4个视觉次。故事情节简单但是有趣，每个故事中会反复出现同一视觉次，有利于反复强化孩子对这单词的记忆。 先按当前阶段把它归为 分级/进阶读物。

## 适合怎么用
- 先读封面和插图，再问 who/what/where/why。
- 按页推进，短读、重复读，不追一次读完。

## 当前判断
- 这类材料更适合做“理解 + 迁移”，不是单纯背词。
- 如果孩子跑神，就缩短到 1-2 页，把互动做完就停。
