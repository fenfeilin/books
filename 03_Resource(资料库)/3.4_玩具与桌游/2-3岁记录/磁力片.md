# 磁力片

**标签**： #玩具 #建构 #形状 #空间 #精细动作

## 简介

家里可能已有。具体品牌、片数和配件待确认。先按开放式建构玩具入库。

## 当前判断

- 2岁3个月可用于形状、颜色、吸住/分开、搭高和简单围合。
- 当前不做复杂图纸复刻；先让孩子自由搭，再把成人语言嵌进去。
- 可和 [[小手乐翻天]] `Magic Shapes`、[[大块积木]]、[[let's grow]] 的场景书联动。

## 2岁3个月低龄玩法

1. 吸住分开：`Stick together.` / `Pull apart.`
2. 颜色配对：`Same color.` / `Different color.`
3. 搭小房子/车站：给 [[快慢狐巴士站台]] 做 stop 或 garage。
4. 形状命名只轻轻带过：`triangle / square`，不要求孩子输出。

## 观察点

- 是否能双手把两片吸住或分开。
- 是否能按颜色找相同。
- 是否会自发围合、搭高或做“家/车站”的假装场景。
