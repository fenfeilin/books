# SG日与夜

**标签**： #拼图 #SmartGames #空间认知 #仿搭 #适龄/2岁+ #3-4岁主力 #精细动作 #视觉辨别

## 简介

SG日与夜对应 SmartGames `Day & Night`。官方适龄 2-6 岁，48 个挑战，1 人游戏；盒内有木质底座、10 个彩色木块、题册和答案。核心玩法是把木块插、叠、排列成题卡上的场景。白天题卡有颜色和细节，夜晚题卡只给轮廓，所以难度会明显上升。

放在 3-4 岁记录里，优先玩“白天”题卡。目标是看图仿搭、识别顺序、理解上下左右和遮挡关系，不急着进入夜晚轮廓题。

## 适合年龄

- 官方适龄：2-6 岁。
- 2-3 岁：自由插木块、命名颜色和形状，做 1-2 个木块的仿搭。
- 3-4 岁：适合白天题卡，成人陪着看图、找第一块、按顺序搭。
- 4-5 岁：可尝试部分夜晚轮廓题，练从轮廓推测具体木块。
- 5-6 岁：逐步独立完成更多题卡，并自己检查是否完全一致。

## 发展能力对应

结合 [[教育部 3-6岁儿童学习与发展指南]]，3-4 岁孩子适合在实际操作中感知大小、高矮、上下、前后、里外；不应把任务变成速度训练或考试。

## 物品使用

- 底座：固定在桌面正中，先告诉孩子“木块要站在底座上”。
- 彩色木块：先按颜色、形状、大小命名，再按题卡顺序取用。
- 白天题卡：看得到颜色和形状，适合 3-4 岁主玩。
- 夜晚题卡：只看轮廓，难度更高；3-4 岁可以只做观察，不要求独立完成。
- 答案：成人用来核对，不用来催孩子“照答案摆”。

## 给孩子讲明白玩法

中文：

1. “这张是白天照片，我们要搭出一样的房子和木块。”
2. “先找最下面的木块，再往上搭。”
3. “每块木头要站稳，颜色和位置要像照片。”
4. “搭好以后，我们从前面看，和照片一样就完成。”
5. “夜晚照片只看到影子，等白天很熟了再玩。”

English:

1. `This is the day picture. Let's build the same scene.`
2. `Find the bottom piece first. Then build up.`
3. `Make it stand. Match the color and the place.`
4. `Look from the front. Is it the same?`
5. `The night picture is a shadow. We can try it later.`

## 陪玩规则

- 先玩白天题卡，不一开始挑战夜晚轮廓。
- 成人先帮孩子找“底下第一块”，降低启动难度。
- 每次只提示一个维度：先位置，再颜色，再方向。
- 木块倒了时先说 `Make it stand.`，不评价孩子手笨。
- 孩子烦躁时减少木块数量，只完成最后 1-2 块也算完成。
- 不用计时，不比较题卡等级。

## 3-4岁降阶带玩脚本

目标先降到：按图找到同色木块、插到底座上、从下往上完成 2-4 块结构。

### 成人示范顺序

1. 选最简单白天题卡，先只拿出题卡会用到的 2-3 块。
2. 成人指题卡最下面：`Bottom first.`
3. 成人拿起对应木块：`Same color.`
4. 让孩子插到底座上：`Put it here. Push down.`
5. 第二块由成人放近正确位置：`On top.`
6. 完成后从正面检查：`Same picture. All done.`

## 退阶玩法

- 不用题卡，只玩把木块插上、拔下、站稳。
- 只用 2 块做仿搭：成人搭一个，孩子搭一个一样的。
- 成人搭好下半部分，孩子只放最上面一块。
- 只看颜色：`Find the red one.`，不要求位置完全正确。
- 夜晚题只用来玩“影子猜猜看”，不要求解题。

## 进阶玩法

- 孩子自己从题卡中找第一块和第二块。
- 完成白天题后，让孩子说出顺序：`red first, blue next`。
- 成人逐步减少手势，只保留语言提示。
- 尝试最简单夜晚题：先让孩子猜轮廓可能是哪几块。
- 搭好后转动角度，让孩子发现“从前面看才和题卡一样”。

## 使用轨迹（按月龄）

- 待记录：进入 3-4 岁后，从白天题卡低阶开始。观察重点是能否按图取物、按顺序插放、遇到倒塌时是否愿意重试。

## 后续候选玩法

- 第一步：底座自由插木块，练 `stand / push down / pull out`。
- 第二步：成人搭 2 块，孩子照搭 2 块。
- 第三步：1 张白天题，成人给出会用到的木块，孩子完成。
- 第四步：1 张白天题，孩子自己从所有木块里找。
- 第五步：夜晚题只看轮廓，先猜不做完整挑战。

## 观察点

- 是否能从题卡迁移到真实木块。
- 是否能理解从下往上搭。
- 是否能控制力度，让木块站稳。
- 是否能从正面检查作品是否一致。
- 是否能接受倒塌、转向、重搭这些自然试错。
