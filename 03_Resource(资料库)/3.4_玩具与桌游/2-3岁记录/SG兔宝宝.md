# SG兔宝宝

**标签**： #拼图 #SmartGames #空间认知 #适龄/2岁+ #3-4岁主力 #精细动作 #问题解决

## 简介

SG兔宝宝对应 SmartGames `Bunny Boo`。官方适龄 2-5 岁，60 个挑战，1 人游戏；盒内主要是木质兔宝宝、3 个木块、任务卡和答案。核心不是普通拼图，而是让孩子照着任务卡，把兔宝宝和木块搭成一样的正面图，练习 `above / below / inside / outside / in front / behind / hidden / visible`。

放在 3-4 岁记录里，可以作为空间方位、观察比较、按图搭建和简单规则执行的主力玩具。这个年龄段不需要追求刷完题卡，重点是让孩子能看图、说位置、试着旋转和调整。

## 适合年龄

- 官方适龄：2-5 岁。
- 2-3 岁：先当木块和兔宝宝做开放搭建，只做 1 个木块 + 兔宝宝的简单仿搭。
- 3-4 岁：适合进入任务卡玩法，但先选低阶卡，成人陪读题卡和提示方位。
- 4-5 岁：可以逐步独立完成简单题卡，并解释“为什么兔子要在这里”。

## 发展能力对应

结合 [[教育部 3-6岁儿童学习与发展指南]]，3-4 岁孩子适合通过直接感知、实际操作和游戏理解空间关系；科学/数学认知里可重点练 `上/下、前/后、里/外`，语言领域可练描述自己看到的图。

结合 [[Pathways.org 儿童发育里程碑与能力观察]]，这个玩具也适合观察手眼协调、双手操作、共同注意、听懂两步以内指令、卡住时是否会求助。

## 物品使用

- 兔宝宝：可以站在木块上、藏在木块后、露出耳朵，也可以从洞里看出来。
- 木块：先按颜色命名，再看洞的形状和方向；不要一上来混讲太多规则。
- 任务卡：把卡立在孩子正前方，只看“正面长什么样”。不是从上往下看，也不是随便搭。
- 答案页：成人收好，先用于确认，不拿给孩子当抄答案。

## 给孩子讲明白玩法

中文：

1. “我们先选一张兔宝宝照片。”
2. “照片上兔宝宝在哪里？在上面、里面，还是藏在后面？”
3. “我们用这几个木块，搭成和照片一样。”
4. “搭好以后，我们站在前面看一看，像不像照片。”
5. “如果不像，就转一转、换一换，再试一次。”

English:

1. `Let's choose one bunny card.`
2. `Where is the bunny? On top, inside, or behind?`
3. `Let's build it with the blocks.`
4. `Look from the front. Does it match the card?`
5. `If it does not match, turn it and try again.`

## 陪玩规则

- 一次只拿 1 张任务卡，其他卡先收走。
- 先看兔子位置，再看木块颜色和洞，不急着让孩子直接搭。
- 成人提示只给一个动作：`turn it`、`put it on top`、`hide it behind`，不要连环提问。
- 卡住时成人先搭好 70%-80%，把最后一步留给孩子完成。
- 不说“错了”，改说“not yet / 还不像照片，我们再看一次”。
- 如果孩子开始乱搭，可以先接纳 1 分钟开放玩法，再回到“照照片搭一次”。

## 3-4岁降阶带玩脚本

目标先降到：看正面图、理解兔宝宝和木块的位置、完成最后一个放置动作。

### 成人示范顺序

1. 只拿 1 张最简单任务卡、兔宝宝和 1-2 个木块。
2. 成人指图：`Bunny. Block. On top.`
3. 成人先放好一个木块。
4. 把兔宝宝放到离正确位置 2-3 厘米处。
5. 指令只说一句：`Put bunny on top.`
6. 拼好后带孩子从正面看：`It matches. Same as the card.`
7. 如果角度不对，成人慢慢转一次：`Turn it. Now look.`

### 亲子英语

- `Bunny.`
- `Block.`
- `On top.`
- `Inside.`
- `Behind.`
- `Look from the front.`
- `Turn it.`
- `Try again.`
- `It matches.`
- `Help, please.`

## 退阶玩法

- 不用任务卡：只玩 `on / in / behind`，成人说位置，孩子摆兔宝宝。
- 只用 1 个木块：练 `on top` 和 `inside`，不要同时出现 3 个木块。
- 成人搭好木块，孩子只放兔宝宝。
- 成人把兔宝宝角度调好，孩子只完成最后的 `press / stand`。
- 如果孩子只想玩角色扮演，就让兔宝宝“回家、睡觉、躲猫猫”，保留方位词输入。

## 进阶玩法

- 孩子自己选一张低阶卡，说出兔宝宝在哪里。
- 成人只问 `What do you see?`，让孩子先观察再动手。
- 完成后让孩子解释：`The bunny is behind the red block.`
- 两张卡对比：哪一张兔子在上面，哪一张兔子在里面。
- 看 5 秒任务卡后盖住，让孩子凭记忆复原一个简单结构。

## 使用轨迹（按月龄）

- 待记录：进入 3-4 岁后，可从最低阶任务卡开始观察。重点不看完成数量，而看孩子是否能看图、说位置、主动旋转、卡住时求助。

## 后续候选玩法

- 第一步：1 个木块 + 兔宝宝，练 `on / in / behind`。
- 第二步：1 张低阶卡，成人搭木块，孩子放兔宝宝。
- 第三步：1 张低阶卡，孩子尝试自己摆，成人只给一个提示。
- 第四步：孩子完成后从正面检查是否和任务卡一样。
- 第五步：让孩子给成人下指令：`Put the bunny inside.`

## 观察点

- 是否能理解“看正面图”，不被俯视角度干扰。
- 是否能说出或指出上、下、里、外、前、后。
- 是否会主动旋转木块或兔宝宝，而不是只等待成人放好。
- 是否能接受“还不像，试一次”的过程。
- 是否能在完成后用中文或英文描述结果。
