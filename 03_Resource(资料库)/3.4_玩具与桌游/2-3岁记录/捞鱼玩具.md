# 捞鱼玩具

**标签**： #玩具 #精细动作 #假装游戏 #水玩具

## 简介

已买。具体品牌和配件未知，先按“捞鱼/抓取/放回”的操作型玩具入库。

## 当前判断

- 适合练手眼协调、腕部控制、等待轮流和假装照料。
- 如果需要装水，注意防滑、防呛水和收纳；不把水玩变成必须完成任务。
- 2岁3个月阶段先只抓 1 个动作：捞起、放回、给鱼回家。

## 2岁3个月低龄玩法

1. 捞一条就结束：`Catch a fish.` / `Put it back.`
2. 分类降阶：只分“大鱼/小鱼”或“红鱼/蓝鱼”，不做复杂分类。
3. 轮流捞：`Mama's turn.` / `Your turn.`，每人只捞 1 条。
4. 生活迁移：接 [[Wplay]] 或 [[古力小超人]] 里的钓鱼/水边主题时，只做 `fish / water / catch / back`。

## 观察点

- 是否能用工具捞起，还是需要手抓。
- 是否能接受只捞 1-3 条后结束。
- 是否能听懂 `put it back` 或 `fish goes home`。
