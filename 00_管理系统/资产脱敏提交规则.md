# 资产脱敏提交规则

## 原则

- 可以提交：产品代码、页面结构、图表逻辑、脱敏示例数据、策略框架。
- 不提交：真实账户、真实持仓、真实金额、导出 CSV/JSON/XLSX、截图、月度明细、备份文件。

## 已创建的 ignore 规则

该项目已创建 `.gitignore`，忽略：

- `node_modules/`
- `dist/`
- `.env*`
- `data/`
- `local-data/`
- `exports/`
- `reports/`
- `backups/`
- `*.csv`
- `*.xlsx`
- `*.xls`
- 普通 `*.json`，但保留 `package.json`、`package-lock.json`、`tsconfig.json`
- `src/data/localData.ts`
- `src/data/privateData.ts`
- `src/data/realData.ts`

## 仍需注意

`.gitignore` 只能挡住未提交的文件，挡不住写在源码和 README 里的真实信息。

目前 `managemoney` 的 `README.md` 和 `src/data/sampleData.ts` 里仍有比较具体的资产金额和账户描述。如果未来要把这个项目提交到远程仓库，建议先把这些内容改成脱敏示例。
