# Obsidian 任务管理改造草案

> 当前草案日期：2026-05-11
> 目标：把育儿、教资、资产管理、博主内容做成一个能持续更新的系统，而不是一堆分散笔记。

## 0. 现状判断

### 已有结构可以保留

- `01_Projects(近期项目)`：适合放正在执行的短期计划；已经结束的月龄计划应归档到 `02_Areas(成长记录)`。
- `02_Areas(成长记录)`：适合放孩子月度记录、阶段汇总。
- `03_Resource(资料库)`：适合放书、玩具、桌游、方法论等长期资源卡片。
- `05_考教资`：已经比较完整，有总计划、每日学习、真题整理、公告追踪。

### 当前缺口

- 育儿缺少“库存录入 -> 每日带读/带玩 -> 次日反馈 -> 月度复盘 -> 采购建议”的闭环。
- 资源笔记有双链雏形，但字段不统一，后续不利于判断是否重复购买、是否适合当前月龄。
- 教资自动化已有，不需要新增日提醒；主要缺口是把每日学习页和知识点、错题、模板建立关联。
- 资产管理内容敏感，应放在 git 忽略路径中；周/月/年总结可以自动化，但要先确定数据来源和输出口径。
- 博主内容目前适合从育儿系统自然长出来：每周资源测评、每月阅读复盘、不定期 AI 育儿经验。

## 2. 育儿系统

### 2.1 日常输入

你可以用三种方式录入新东西：

- 直接输入清单：例如“新买：小彼恩CP红盒、鼠小弟2、HABA购物清单”。
- 拍照后补充文字：至少给封面、书脊、目录或套装清单，方便识别版本。
- 购物订单批量复制：商品标题、规格、购买日期、价格、链接。

如果我无法从互联网或图片中确认产品，需要你补充这些字段：

- 准确名称：中文名、英文名、系列名、级别、版本。
- 类型：绘本、分级、童谣、机关书、桌游、玩具、教具、课程。
- 分册或组件清单：一套里面具体有什么。
- 适龄标注：商家建议适龄，以及你自己的判断。
- 当前状态：已拥有、想买、已下单、已闲置、准备出二手。
- 点读/音频：是否支持小彼恩或其他点读，音频是否匹配。
- 孩子反馈：喜欢、抗拒、卡认知、能复述、能迁移到生活。
- 购买信息：价格、渠道、是否可退、是否重复。

### 2.3 每日计划

当前工作假设：近期主目标先放在“认知理解 + 语言迁移”，英语启蒙作为载体，不把升级分级难度当作唯一目标。原因是已有记录里出现了“能背诵但不一定能灵活运用”“颜色/数数/推理还不稳”“故事变长容易跑”“对投递、喂食、开关、门等操作很感兴趣”。所以短期更适合短故事、生活场景迁移、分类匹配、因果提问、轮流等待和精细动作。

每天只做一个轻量但可执行的组合：

- 读：1 本主力旧书 + 1 本新/进阶书。
- 玩：1 个桌游/玩具动作目标，控制在 5-10 分钟。
- 观察：只记录 1-3 个信号，例如“能否回答为什么”“能否轮流等待”“能否从图里主动讲”。
- 拓展：给一段可直接照着说的中文/英文互动话术。

每天计划需要使用这些输入：

- 昨天反馈。
- 当前月龄记录。
- 已拥有库存。
- 最近卡点：认知、语言运用、颜色、数数、社交、精细动作等。
- 家长当天可用时间：5 分钟、15 分钟、30 分钟。

### 2.4 次日反馈

你第二天只需要填最短版本：

```markdown
昨天实际做了：
孩子喜欢：
孩子抗拒/卡住：
出现的新输出：
我今天可陪伴时间：5/15/30分钟
```

我再据此调整当天策略：继续重复、降级、换玩法、暂缓、推进。

### 2.5 周计划

每周做四件事：

- 整理本周新增资源，判断是否重复、是否当前可用。
- 生成下周 5-7 天带读/带玩候选池。
- 选 1 个博主主题：一套绘本、桌游、玩具或一个育儿方法。
- 把 `育儿收件箱` 中的碎片归档到资源卡、方法论、月度记录或未来提醒。

### 2.6 月计划

每月输出一篇月报：

- 本月读了什么、玩了什么。
- 孩子掌握了什么：语言、认知、精细动作、规则意识、生活迁移。
- 还欠缺什么：例如推理、颜色、数数、主动社交、故事理解。
- 下月主线：继续重复什么、引入什么、暂缓什么。
- 购买建议：需要买、可以等等、不建议买、重复可替代。
- 博主内容：一篇“娃这个月读了什么”。

### 2.7 年计划

每年或每半岁做阶段复盘：

- 0-1、1-2、2-3、3-4 岁阶段阅读轨迹。
- 红榜、黑榜、踩坑原因。
- 资源保留/出二手清单。
- 下一阶段书单和玩具路线。
- 可沉淀为博主长文的经验主题。

## 3. 碎片内容系统

碎片不直接塞进月记录，先进入 `育儿收件箱`，周整理时再分类：

- 资源相关：归到具体书/玩具卡片。
- 发展观察：归到当月成长记录。
- 教育观点：归到 `03_Resource(资料库)/3.6_育儿方法论`。
- 未来提醒：归到对应年龄段或主题页，例如 `英语启蒙-小学阶段提醒.md`。
- 博主素材：同步放入内容池。

例如：“一二年级不适合学习 think 原版教材”可以归档为：

- `03_Resource(资料库)/3.6_育儿方法论/英语原版教材选择.md`
- 标签：`#英语启蒙 #小学阶段 #教材选择 #待验证`
- 未来触发点：孩子 5 岁、幼小衔接、一年级前、研究 Think 主题时再看。

## 4. 博主内容系统

### 6.2 周计划

每周输出：

- 本周资产变化：总资产、各类资产比例、现金、固收、A股、美股、黄金、主题仓。
- 交易/定投执行情况：是否按计划买入，是否偏离节奏。
- 风险提示：单类资产偏离目标、主题仓过大、现金不足、未来 3 年用钱安排。
- 下周动作：买什么、不买什么、需要人工确认什么。

### 6.3 月计划

每月输出：

- 目标配置 vs 实际配置。
- 建仓进度：是否还在 8-10 个月建仓期。
- 再平衡判断：是否超过阈值。
- 现金流和大额支出预案。
- 下月策略：按计划、减速、加速、暂缓。

### 6.4 年计划

每年输出：

- 年度收益和最大回撤。
- 资产配置是否仍符合家庭目标。
- 是否需要调整股债比例、黄金比例、主题仓上限。
- 税务、账户、家庭现金流、保险和应急金复盘。
