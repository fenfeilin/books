# 2026广州中职计算机类教师资格证备考包

## 1. 报考方向建议

推荐优先报考：中等职业学校专业课教师资格 - 计算机类，面试方向建议选“计算机应用 / 软件与信息服务 / 计算机网络技术 / 程序设计基础”中最贴近报名系统可选项的一项。

理由：
- 学员本职是程序员，研究生和本科为机械背景，转码后有真实工程经验。中职专业课比高中信息技术更能承接“项目开发、程序设计、数据库、Web、网络基础”等实践内容。
- 中职学生更重视“会做、能演示、能解决问题”，程序员经历可以转化成教学优势。
- 若目标是偏编程，面试试讲更容易围绕 Python / Java / Web / 数据库 / 算法基础设计一节 10 分钟课。

备选方向：
- 高中信息技术：更标准化，资料多，但需要参加科目三《信息技术学科知识与教学能力》，且内容偏普高课程标准、信息素养、算法与数据、信息系统等。
- 中职实习指导教师：更偏实操与技能训练，但部分地区可能对学历、技术等级或工作经历有额外要求，需等广东下半年公告确认。

结论：以“中职专业课教师资格 - 计算机类”为主线准备；同时用“高中信息技术”的学科知识资料补足计算机教学设计和试讲素材。

## 3. 考试科目与复习重心

中职专业课教师资格一般笔试准备：
- 科目一：301《综合素质》（中学）
- 科目二：302《教育知识与能力》（中学）
- 科目三：《专业知识与教学能力》通常结合面试环节由省级组织或在面试中考查，广东具体口径以公告为准。

科目一重点：
- 职业理念：学生观、教师观、素质教育观。
- 教育法律法规：教师法、教育法、未成年人保护、预防未成年人犯罪、学生伤害事故处理。
- 教师职业道德：三爱两人一终身。
- 文化素养：文学、历史、科技常识，靠题感和积累。
- 基本能力：阅读理解、逻辑推理、信息处理、作文。

科目二重点：
- 教育基础知识与基本原理。
- 中学课程。
- 中学教学。
- 中学生学习心理。
- 中学生发展心理。
- 中学生心理辅导。
- 中学德育。
- 中学班级管理与教师心理。

面试/专业课重点：
- 结构化问答：教育情境、职业认知、班级管理、应急应变。
- 试讲：导入、目标、重点难点、活动设计、板书、总结、作业。
- 答辩：为什么这样教、学生不会怎么办、如何评价。
- 计算机专业课素材：Python 基础、变量与数据类型、条件语句、循环、函数、列表、HTML/CSS、数据库基础、网络基础、信息安全、软件开发流程。

## 6. 阶段计划

第一阶段：2026-05-09 至 2026-06-15，搭框架
- 科目一：职业理念、法律法规、职业道德。
- 科目二：教育基础、课程、教学。
- 每周 1 次作文素材积累。
- 输出：科一/科二各一张思维导图。

第二阶段：2026-06-16 至 2026-07-31，刷题和模板
- 科目一：选择题每日 10-15 题，作文每 2 周 1 篇。
- 科目二：主观题模板背诵，简答/材料分析每周各 3 题。
- 面试：开始积累 10 个计算机试讲课题。
- 输出：错题本、主观题答题模板、试讲课题清单。

第三阶段：2026-08-01 至 2026-08-31，真题训练
- 每周至少 1 套科目一真题 + 1 套科目二真题。
- 科目二主观题按关键词给分训练。
- 作文固定结构：立意、教育观点、案例、回扣教师职业。
- 输出：真题得分表，低于 70% 的章节回炉。

第四阶段：2026-09-01 至 2026-09-11，考前冲刺
- 只看错题、模板、法律法规高频点。
- 每天 1 组材料分析题。
- 作文只练审题和提纲。
- 考前 3 天减少新题，保证睡眠。

第五阶段：笔试后至面试，专业试讲
- 每周 3 次 10 分钟试讲。
- 每次录音或录像，检查语速、板书、过渡语。
- 准备 10 套计算机专业课教案。

## 9. 计算机试讲通用模板

课题：Python if 条件语句

导入：
用“登录系统判断密码是否正确”的场景引出条件判断。

教学目标：
- 知识与技能：理解 if 语句的基本结构。
- 过程与方法：通过案例调试掌握条件表达式。
- 情感态度价值观：形成严谨的程序逻辑意识。

重点：
if 语句结构和条件表达式。

难点：
缩进、条件真假、分支执行路径。

教学过程：
1. 情境导入：展示登录判断需求。
2. 新知讲解：讲 if 基本语法。
3. 示例演示：输入成绩，判断是否及格。
4. 学生活动：改写代码，加入优秀/良好/及格分支。
5. 总结提升：条件判断让程序具备选择能力。
6. 作业：设计一个年龄判断的小程序。

板书：
if 条件:
    语句块
elif 条件:
    语句块
else:
    语句块
