## 18:30 微课讲义

### 今天考什么

科二“教学原则”常考两类：

- 单选题：给一个课堂行为，问体现了哪条教学原则。
- 材料分析题：给一段课堂实录，问主要体现了什么原则，并要求写基本要求。

今天只抓高频四个：

- 直观性原则：用实物、模型、图片、视频、演示等帮助学生形成清楚表象。
- 启发性原则：通过提问、情境、讨论，引导学生主动思考和探索。
- 理论联系实际原则：把知识原理和生活、生产、社会实践联系起来，做到学以致用。
- 因材施教原则：承认学生差异，按学生基础、能力、兴趣安排教学。

### 一、先看老师做了什么

做题时不要先背原则定义，先把题干压缩成一句“老师做了什么”。

- 老师展示模型、图片、实验现象、视频：优先想直观性原则。
- 老师用问题链、情境冲突、讨论推动学生自己想：优先想启发性原则。
- 老师讲完知识后让学生解释生活现象、解决真实任务：优先想理论联系实际原则。
- 老师给不同学生不同任务、分层要求、关注个体差异：优先想因材施教原则。

### 二、最容易混的两组

直观性 vs 演示法：

- 直观性原则是“教学要求”，强调帮助学生形成感性认识。
- 演示法是“教学方法”，强调教师展示实物、教具或实验过程。
- 如果题目问“原则”，选直观性；如果问“方法”，选演示法。

启发性 vs 问答法：

- 启发性原则强调调动学生主动思考。
- 问答法是具体方法，不是所有提问都算启发。只有问题能推动学生思考、探究、概括时，才体现启发性。

### 三、和中职计算机课连起来

如果试讲“HTML 表格和 CSS 布局”，可以这样体现原则：

- 直观性：展示两个页面截图，一个用表格布局，一个用 CSS 布局，让学生观察差异。
- 启发性：提问“如果页面要适配手机，表格布局会遇到什么问题？”
- 理论联系实际：让学生把学校社团报名页改成响应式布局。
- 因材施教：基础弱的学生完成颜色和文字修改，基础好的学生完成弹性布局优化。

### 今天最该记的一句话

`教学原则题先看课堂行为：看得见的是直观，想得动的是启发，用得上的是联系实际，分得开的是因材施教。`

## 输出样例

### 简答题片段：贯彻启发性教学原则的基本要求

关联模板：[[简答题模板]]、[[科二-教学方法与教学原则]]

题目：简述贯彻启发性教学原则的基本要求。

1. 第一，加强学习目的性教育，调动学生学习的主动性。
2. 第二，启发学生独立思考，发展学生的逻辑思维能力。
3. 第三，鼓励学生动手实践，培养独立解决问题的能力。
4. 第四，发扬教学民主，营造平等、开放的课堂氛围。

中职计算机课堂可这样改写：

在讲“条件语句”时，教师不直接给出全部代码，而是创设“成绩等级判断”的任务情境，让学生先分析输入、条件和输出，再通过追问引导学生发现边界值 60、80、90 容易出错。这样既能调动学生主动思考，也能培养学生分析问题和解决问题的能力。

可套用句：

`教师通过问题情境和层层追问，引导学生主动思考、积极探索，体现了启发性教学原则。`

## 练习题

说明：今天共 10 题，前 7 题来自本地真题或真题改编，后 3 题为原创巩固。最低完成版只做第 1、2、3、4、8 题。错题可记录到 [[错题索引]] 或 [[科二-教学方法与教学原则]]。

### 1.

【本地真题｜2025上 科二】生物课上，李老师通过模具视频展示 DNA 的双螺旋模型，帮助学生认识 DNA 的结构。李老师主要遵循的教学原则是？

答案：直观性原则。

解析：教师借助模具视频帮助学生形成具体表象，降低抽象知识理解难度。

做题思路：看到“模型、视频、图像、实物展示”，优先判断直观性原则。

### 2.

【本地真题｜2023下 科二】教师引导学生通过观察所学事物的图像，或用语言形象地描绘对象，帮助学生形成具体而清晰的表象。该教师遵循的教学原则是？

答案：直观性原则。

解析：直观性原则强调通过实物直观、模象直观或语言直观帮助学生理解知识。

做题思路：题干直接出现“观察图像、形成表象”，不要选启发性。

### 3.

【本地真题｜2021下 科二】学完“压强”概念后，教师要求学生举例说明该原理在生活中的应用。该教师主要贯彻的教学原则是？

答案：理论联系实际原则。

解析：教师引导学生把课堂原理用于分析生活现象，体现学以致用。

做题思路：看到“学完原理 -> 举生活应用”，优先选理论联系实际。

### 4.

【本地真题｜2023上 科二】地理课上，刘老师通过“船在太平洋遇险如何报告位置”的情境设问，引导学生讨论如何确定位置，进而理解经纬线和经纬网。主要体现的教学原则是？

答案：启发性教学原则。

解析：教师通过问题情境和追问调动学生主动思考，使学生在讨论中理解概念。

做题思路：看到“情境设问、追问、讨论、学生自己想出来”，优先选启发性。

### 5.

【本地真题｜2022上 科二】简述贯彻启发性教学原则的基本要求。

答案：加强学习目的性教育；启发学生独立思考；鼓励学生动手，培养独立解决问题的能力；发扬教学民主。

解析：简答题不要求写长文，4 点踩中关键词即可。

做题思路：启发性原则的关键词是“主动性、独立思考、动手解决、教学民主”。

### 6.

【真题改编｜2024下 科二】新学期开始，教师先测了解学生知识水平和能力，再据此安排后续教学。该做法最有利于贯彻哪项教学原则？

答案：因材施教原则。

解析：教师先了解学生差异，再调整教学安排，体现从学生实际出发。

做题思路：看到“了解学生水平、根据差异安排”，优先找因材施教。

### 7.

【真题改编｜2021上 科二】教师讲“磷及其化合物”时，用“鬼火”现象说明磷化氢自燃原因，并进行无神论教育。该做法主要贯彻哪项教学原则？

答案：科学性与思想性相统一原则。

解析：教师既讲科学知识，又引导学生形成正确思想认识，体现科学性和思想性统一。

做题思路：看到“科学知识 + 思想教育/价值引导”，找科学性与思想性统一原则。

### 8.

【原创巩固】中职计算机课上，教师展示一个混乱的网页和一个结构清晰的网页，让学生观察差异后总结 HTML 语义化标签的作用。主要体现哪项教学原则？

答案：直观性原则，也体现启发性原则。

解析：展示网页样例是直观性；让学生观察并总结是启发性。单选时若重点在“展示观察”，优先选直观性。

做题思路：材料题可分层写；单选题要抓题干最强调的动作。

### 9.

【原创巩固】教师讲完 if 条件语句后，让学生为“考试成绩等级判断”设计边界值测试案例。主要体现哪项教学原则？

答案：理论联系实际原则。

解析：教师把语法知识迁移到真实程序任务中，训练学生解决实际问题。

做题思路：看到“学完知识后完成真实任务、解决实际问题”，优先选理论联系实际。

### 10.

【原创巩固】同一节 Python 课，教师要求基础弱的学生完成变量赋值和输出，基础好的学生增加输入校验和异常提示。该做法体现哪项教学原则？

答案：因材施教原则。

解析：教师根据学生基础设置分层任务，照顾个体差异。

做题思路：看到“分层任务、不同要求、照顾差异”，选因材施教。
