# Littlebean 资源下载提示词

把下面内容复制给 AI，再补充 Littlebean 页面链接或 txt 文件路径。

```txt
请帮我分析并下载 Littlebean 页面中公开暴露的音频/视频资源。

要求：
1. 先分析资源，不要立刻下载。
2. 输出页面标题、MP3 数量、MP4 数量、资源是否较大、建议下载范围。
3. 等我确认后再下载：全部资源、只下载音频、只下载视频，或指定序号。
4. 下载到我指定的目标目录；如果是多本书，按“行号 - 书名”建立子文件夹。
5. 文件已存在且非空时跳过，方便中断后重跑补齐。
6. 只下载页面或公开 API 返回的资源，不绕过登录、付费或权限。
```

## 支持的页面

- `song` 页面：通常是 MP3 音频。
- `bookdetail` 页面：通常包含 MP3 音频、MP4 视频、介绍视频。

## 批量下载

如果有很多链接，可以放进 txt，一行一个：

```txt
https://littlebean.baobaobooks.com/h5/bookdetail/v2?xbe_book_id={xbe_book_id}&index=1
```

处理规则：

- 每一行对应一个下载文件夹。
- 文件夹名优先用：`行号 - 书名`。
- 如果接口拿不到书名，用：`行号 - book_{xbe_book_id}`。
- 已存在且非空的文件跳过。

## 常用接口

从链接里取 `xbe_book_id`。

查书名：

```txt
https://littlebean.baobaobooks.com/xiaobienapi/bookshelf/v1/v3_3_0/books/{xbe_book_id}
```

查音频列表：

```txt
https://littlebean.baobaobooks.com/xiaobienapi/bookshelf/v1/v3_3_0/user/audios?book_id={xbe_book_id}
```

备用接口：

```txt
https://littlebean.baobaobooks.com/xiaobienapi/bookshelf/v1/xiaobien/books/{xbe_book_id}
https://littlebean.baobaobooks.com/xiaobienapi/bookshelf/v1/v2_1_4/{xbe_book_id}/audios
```

请求头可参考：

```txt
X-HB-Client-Type: xiaobien-mobile
Wechat-Url: 原 Littlebean 页面链接
X-HB-Token:
User-Agent: Mozilla/5.0
```

音频链接字段优先看：

```txt
resource_url
```

文件名建议：

```txt
序号 - resource_name - first_type_name sec_type_name.mp3
```

## 按书名找资源

如果只有书名，可以先搜索：

```txt
https://littlebean.baobaobooks.com/littlebeanapi/api/search/goods?keywords={书名关键词}&page=1
```

注意：

- 搜索结果里的 `goods_id` 是商品 ID，不一定是 `xbe_book_id`。
- 商品详情可以查封面、轮播图、详情长图等图片资源。
- 书籍音频通常仍需要真正的 `xbe_book_id`。

商品详情接口：

```txt
https://littlebean-api.baobaobooks.com/api/goods/{goods_id}
```

商品详情里可检查：

- `goods_thumb`
- `book_image`
- `images[].image`
- `goods_desc` / `goods_mobile_desc` 里的 `<img src="...">`
- `audio_num` / `video_num`

## 图片、PDF、电子资源

图片：

- 先看商品详情的 `images`。
- 再解析 `goods_mobile_desc` 里的所有 `<img src="">`。
- 保存到用户指定目录。

PDF 或电子档：

在商品详情 JSON 里搜索：

```txt
pdf
epub
zip
rar
doc
docx
```

如果没有相关链接，通常公开接口里没有电子档。
