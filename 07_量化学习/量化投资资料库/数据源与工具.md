# 数据源与工具

## 数据源优先级

| 阶段 | 数据源 | 用法 |
|---|---|---|
| 入门 | AKShare | 免费获取行情、指数、基础数据，适合研究原型 |
| 进阶 | Tushare Pro | A 股数据较系统，需要 token 和积分 |
| 平台 | 聚宽、米筐、掘金 | 快速验证策略和使用平台数据 |
| 补充 | ftshare | 可作为补充数据源，后续比较覆盖和口径 |

## 本地研究技术栈

| 层 | 建议 |
|---|---|
| 数据处理 | pandas / polars |
| 存储 | parquet / duckdb |
| 配置 | yaml / pydantic |
| 调度 | cron / prefect / dagster |
| 图表 | matplotlib / plotly |
| 报告 | markdown / html |
| 回测 | 先自研轻量日频框架 |

## 数据层注意事项

- 股票列表必须是历史时点股票池，避免只用当前存活股票。
- 财报因子必须使用公告日期，而不是报告期日期。
- 复权价格和原始价格要区分：收益计算常用复权，交易价格约束常用真实价格。
- 涨跌停、停牌、ST、上市天数、成交额过滤要进入回测约束。
