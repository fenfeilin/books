# 推荐书课

## 优先读

1. 《主动投资组合管理》：理解 Alpha、风险、因子、组合管理。
2. 《因子投资：方法与实践》石川：更贴近中文语境和 A 股因子研究。
3. 《Expected Returns》Antti Ilmanen：理解不同资产和风格收益来源。
4. Quantopian Lectures：程序员友好的量化研究流程。

## 稍后读

1. 《Advances in Financial Machine Learning》：机器学习量化进阶，不建议太早读。
2. Barra 风险模型相关材料：用于理解风格暴露、行业暴露和风险分解。
3. 券商金工研报：华泰、开源、方正、国君等的因子和组合研究。

## 阅读方法

- 不追求一次读完。
- 每读一个概念，落到一个可计算指标。
- 每读一个策略，问：数据从哪来、何时可见、如何交易、成本多少、何时失效。
