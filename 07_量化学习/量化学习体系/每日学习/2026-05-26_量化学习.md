### 1. 日行情字段

一张最基础的日行情表，至少应该有：

| 字段 | 含义 | 用途 |
|---|---|---|
| trade_date | 交易日 | 时间轴、调仓日 |
| symbol | 股票代码 | 主键 |
| open | 开盘价 | 开盘成交假设 |
| high | 最高价 | 波动、突破 |
| low | 最低价 | 回撤、止损触发 |
| close | 收盘价 | 收益计算、信号计算 |
| volume | 成交量 | 流动性约束 |
| amount | 成交额 | 流动性过滤、容量估计 |
| pre_close | 昨收 | 涨跌幅、涨跌停判断 |
| limit_up | 涨停价 | 是否可买 |
| limit_down | 跌停价 | 是否可卖 |
| paused | 是否停牌 | 是否可交易 |
| is_st | 是否 ST | 股票池过滤 |

### 2. 复权价和真实价

复权价适合研究收益，真实价适合模拟交易。

- 计算过去 20 日收益：用复权收盘价。
- 判断今天是否涨停：用未复权真实价格和涨停价。
- 模拟买入成交价：用真实开盘价、收盘价或 VWAP 假设。
- 画长期价格趋势：通常用前复权价。

### 3. 交易日历

不要用自然日推断交易日。A 股有周末、节假日、临时休市，所有回测都应该基于交易日历。

常见错误：

- 用 `date + 1 day` 当作下一个交易日。
- 在非交易日生成调仓信号。
- 用月末自然日调仓，而不是月末最后一个交易日调仓。

### 4. 沪深 300 股票池

你选沪深 300 很适合入门，但要注意两种股票池口径：

| 口径 | 含义 | 风险 |
|---|---|---|
| 当前成分股 | 用今天的沪深 300 成分回测历史 | 有幸存者偏差 |
| 历史成分股 | 每个历史日期使用当时的成分 | 更真实，但数据更难 |

入门阶段可以先用当前成分股练流程，但报告里要明确标注：这是研究原型，不是严谨回测。

### 正确点

1. 复权价和真实价的核心差异说对了：拆股、分红、送转会让真实价格出现跳变，如果直接用真实价格算收益，会把公司行为误认为暴跌或暴涨。
2. `daily_bar` 表结构已经接近可用，主键、OHLCV、成交额、昨收、涨跌停、停牌、ST、复权因子都覆盖到了。
3. 你能把 `adj_factor` 单独列出来，这个很好。工程上保留复权因子比只存一套复权价更灵活。
4. 当前沪深 300 成分股不能直接回测历史，这个判断对。它会排除历史上被剔除的差样本，导致策略看起来更稳。
5. `get_next_trade_date` 不能 `date + 1` 的原因也抓到了：周末和法定节假日都不是交易日。

### 主要问题

1. 第 1 题还可以更精确：复权价不是“不能交易”，而是“不是市场真实成交价”。它适合算连续收益和历史指标，但不能拿来模拟成交。
2. `close` 的用途写成“生成交易信号”可以，但如果信号用当天收盘价生成，通常只能在下一个可交易时点成交。这里要小心信号时间和成交时间，避免未来函数。
3. `high == limit_up` 只能说明日内碰过涨停，不代表你一定买不进。更关键的是你下单时点的价格、盘口队列和成交假设。日频回测里常见保守规则是：如果开盘一字涨停，则不能买；如果收盘涨停，可以认为收盘买入困难。
4. 沪深 300 的幸存者偏差不只是“暴跌股票被筛掉”，还包括行业权重变化、市值排序变化、成分股定期调整、并购退市和长期表现差导致被剔除。
5. `get_next_trade_date` 应该明确依赖交易日历表，而不是只“避开周末节假日”。实际实现最好查 `trade_calendar` 中 `is_open = true` 的下一条记录。

### 补充解释

今天你已经跨过第一道门了：不是在学一堆名词，而是在设计一套不会骗自己的数据模型。量化系统里，`daily_bar` 不是孤立存在的，它至少要和两张表配合：

1. `trade_calendar`：告诉你哪些日期能交易、上一个/下一个交易日是什么。
2. `universe_membership`：告诉你某一天某只股票是否属于你的股票池，比如是否属于沪深 300。

这样你后面做因子时，才知道“某个信号在当时是否可见、某只股票当时是否可选、下一个成交日是哪天”。

### 需要重做/补充

不用重做。建议补充两列到你的 `daily_bar`：

1. `turnover_rate`：换手率，用于流动性、拥挤度和交易活跃度判断。
2. `listed_days` 或 `list_date`：用于剔除上市未满 N 天的新股。
