### 1. 日行情字段

一张最基础的日行情表，至少应该有：

| 字段 | 含义 | 用途 |
|---|---|---|
| trade_date | 交易日 | 时间轴、调仓日 |
| symbol | 股票代码 | 主键 |
| open | 开盘价 | 开盘成交假设 |
| high | 最高价 | 波动、突破 |
| low | 最低价 | 回撤、止损触发 |
| close | 收盘价 | 收益计算、信号计算 |
| volume | 成交量 | 流动性约束 |
| amount | 成交额 | 流动性过滤、容量估计 |
| pre_close | 昨收 | 涨跌幅、涨跌停判断 |
| limit_up | 涨停价 | 是否可买 |
| limit_down | 跌停价 | 是否可卖 |
| paused | 是否停牌 | 是否可交易 |
| is_st | 是否 ST | 股票池过滤 |

### 2. 复权价和真实价

复权价适合研究收益，真实价适合模拟交易。

- 计算过去 20 日收益：用复权收盘价。
- 判断今天是否涨停：用未复权真实价格和涨停价。
- 模拟买入成交价：用真实开盘价、收盘价或 VWAP 假设。
- 画长期价格趋势：通常用前复权价。

### 3. 交易日历

不要用自然日推断交易日。A 股有周末、节假日、临时休市，所有回测都应该基于交易日历。

常见错误：

- 用 `date + 1 day` 当作下一个交易日。
- 在非交易日生成调仓信号。
- 用月末自然日调仓，而不是月末最后一个交易日调仓。

### 4. 沪深 300 股票池

你选沪深 300 很适合入门，但要注意两种股票池口径：

| 口径 | 含义 | 风险 |
|---|---|---|
| 当前成分股 | 用今天的沪深 300 成分回测历史 | 有幸存者偏差 |
| 历史成分股 | 每个历史日期使用当时的成分 | 更真实，但数据更难 |

入门阶段可以先用当前成分股练流程，但报告里要明确标注：这是研究原型，不是严谨回测。

| 序号 | 字段名 (Field) | 数据类型 (Type) | 含义 | 用途说明 (为什么需要它) |
| :--- | :--- | :--- | :--- | :--- |
| **1** | `trade_date` | DATE | 交易日 | **【主键】** 记录行情发生的具体日期，用于时间序列对齐。 |
| **2** | `symbol` | VARCHAR | 股票代码 | **【主键】** 确定是哪只股票（如 `000001.SZ`）。 |
| **3** | `open` | DECIMAL | 真实开盘价 | 模拟实盘中以每天开盘第一笔成交的假设价格。 |
| **4** | `high` | DECIMAL | 真实最高价 | 计算日内最大波动、判断是否触碰涨停板、突破策略的触发条件。 |
| **5** | `low` | DECIMAL | 真实最低价 | 计算日内最大回撤、判断是否触碰跌停板、止损策略的触发条件。 |
| **6** | `close` | DECIMAL | 真实收盘价 | 每天最核心的价格，用于生成交易信号。 |
| **7** | `volume` | BIGINT | 成交量(股) | 判断股票活跃度。如果你买入的股数超过了今天总成交量的某一部位（比如5%），说明你的资金太大，买不进去了。 |
| **8** | `amount` | DECIMAL | 成交额(元) | 也是流动性指标。一般量化策略会过滤掉每天成交额太小（如小于5000万）的微盘股，防范踩踏风险。 |
| **9** | `pre_close` | DECIMAL | 真实昨收价 | 用来计算今天的真实涨跌幅 `(close / pre_close - 1)`。 |
| **10** | `limit_up` | DECIMAL | 涨停价 | **【交易约束】** 如果 `high == limit_up`，说明今天摸过涨停；如果你要买入时价格是涨停价，系统应拒绝你的买单（买不进）。 |
| **11** | `limit_down` | DECIMAL | 跌停价 | **【交易约束】** 作用同上。如果想卖出时遇到跌停价，系统应判定卖出失败（逃不掉）。 |
| **12** | `paused` | BOOLEAN | 是否停牌 | **【交易约束】** `True`表示今天停牌，任何买卖指令都无效。 |
| **13** | `is_st` | BOOLEAN | 是否ST | **【股票池过滤】** `True`表示是风险警示股，通常量化选股第一步就是把它们全部剔除。 |
| **🌟14** | `adj_factor` | DECIMAL | **复权因子** | **【工程核心】** 这个极其重要！通过它，你可以随时计算出**复权价**。 |
