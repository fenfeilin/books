# 量化学习总览

## 目标

用程序员视角，在 12 周内搭出一套可重复验证的 A 股因子研究体系：数据层、因子层、评估层、组合层、回测报告和复盘机制。

## 学习节奏

每天一次学习任务，结构固定为：

1. 昨日作业批改
2. 今日主题讲解
3. 今日阅读/实验
4. 今日作业
5. 明日检查点

## 12 周路线

| 周次 | 主题 | 产出 |
|---|---|---|
| 第 1 周 | A 股市场机制与数据字段 | 市场规则笔记、数据字段字典 |
| 第 2 周 | 行情数据、复权、交易日历 | 本地日行情数据层设计 |
| 第 3 周 | 收益、回撤、波动、换手 | 基础指标函数 |
| 第 4 周 | 动量、反转、波动、流动性因子 | 第一批价格量因子 |
| 第 5 周 | IC、RankIC、分组回测 | 因子评估报告模板 |
| 第 6 周 | 财务数据与披露滞后 | 财报口径和防未来函数规则 |
| 第 7 周 | 价值、质量、成长因子 | 基本面因子库 |
| 第 8 周 | 去极值、标准化、中性化 | 因子预处理模块 |
| 第 9 周 | 多因子合成 | 多因子评分模型 |
| 第 10 周 | 组合构建与调仓 | TopN 组合回测 |
| 第 11 周 | 成本、滑点、停牌、涨跌停 | 更真实的回测约束 |
| 第 12 周 | 策略复盘与长期跟踪 | 每周研究报告和观察清单 |

## 当前优先级

- [ ] 建立量化学习日志
- [ ] 完成 A 股交易规则速记
- [ ] 定义本地数据层字段
- [ ] 实现第一个价格量因子
- [ ] 跑通 IC 和分组回测

## 核心原则

- 先研究流程，后追求收益。
- 先日频低频，后分钟级和高频。
- 先可解释因子，后机器学习。
- 每个结论必须能被数据、图表、回测和复盘支持。
